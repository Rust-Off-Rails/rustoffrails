# Brand

The mark is **`\R/` derailing**: an R tipping off two rails, with sparks where it hits. The wordmark is "Rust *off* Rails", with "off" in an italic serif, hopping off the baseline. All of it was drawn as code (SVG) by an agent, with the text outlined into paths, so nothing depends on fonts being installed.

| File | Use |
|------|-----|
| `logo.svg` | The canonical mark, on its rounded tile (64px and up) |
| `favicon.svg`, `favicon.ico` (16/32/48) | Browser tabs. A simplified mark without sparks, so it stays crisp at 16px |
| `mark-mono.svg` | One colour (`currentColor`): print, embossing, inline icons |
| `icon-square.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | App icons (full bleed; the platform rounds them) |
| `lockup-on-light.svg/.png`, `lockup-on-dark.svg/.png` | Mark + wordmark |
| `wordmark-*-text.svg` | Wordmark alone, dark or light text |
| `logo-1024.png` | Large raster (social, slides) |

Colours: ember gradient `#ff6b2c → #ffb547`, ink `#1a0b03`, accent `#e8650f` (light) / `#ff8a3d` (dark). Fonts: Bricolage Grotesque 800, Instrument Serif Italic.
