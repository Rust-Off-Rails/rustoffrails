Turn on the assistant

Bring your own provider and key. Set these in .env and restart the server:

DASHBOARD_AI_PROVIDER=anthropic
DASHBOARD_AI_API_KEY=…
# DASHBOARD_AI_MODEL=claude-sonnet-5-5   (or claude-opus-5-5, claude-haiku-5-5)

Any OpenAI-compatible endpoint works too: DASHBOARD_AI_PROVIDER=openai-compatible with DASHBOARD_AI_BASE_URL=https://openrouter.ai/api/v1 (OpenRouter) or http://localhost:11434/v1 (Ollama), and DASHBOARD_AI_MODEL.

It investigates with read-only tools over what the dashboard already redacted (SQL fingerprints, route patterns, names and types, allowlisted source files), shows every step, and never changes anything. You see the first request before anything is sent. The key is never shown, logged or stored.
