Lab: UX trouble

Four ways a page frustrates people, for the dev dashboard's Frontend tab: click each a few times, then look there. Play it by itself.

  • A slow button

    Its request takes 1.4 s and it gives no feedback, so people click again.

  • A dead button

    It looks like a button and does nothing.

  • A button that throws

    Its handler throws a JavaScript error, so the click does nothing.

  • A widget that only works on a full load

    Its script waits for the page's load event. Follow this link (boosted: hx-boost swaps the body, and that event never comes again) and its "Show" button is dead; reload that page and it works.
