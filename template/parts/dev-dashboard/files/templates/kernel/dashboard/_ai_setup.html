Turn on the assistant

Bring your own provider and key. Put one of these in .env and restart the server; everything else on this page already works without it.

Anthropic 
DASHBOARD_AI_PROVIDER=anthropic
DASHBOARD_AI_API_KEY=…
# DASHBOARD_AI_MODEL=claude-sonnet-5-5

claude-opus-5-5 deeper, claude-haiku-5-5 cheaper.

OpenRouter cheap and fast 
DASHBOARD_AI_PROVIDER=openai-compatible
DASHBOARD_AI_BASE_URL=https://openrouter.ai/api/v1
DASHBOARD_AI_API_KEY=sk-or-…
DASHBOARD_AI_MODEL=deepseek/deepseek-v4.1-flash

Or openai/gpt-6-luna, z-ai/glm-5.3-flash: cents per investigation (DeepSeek V4.1 Flash lists $0.04 per million input tokens). Check each model's data policy first.

A local model 
DASHBOARD_AI_PROVIDER=openai-compatible
DASHBOARD_AI_BASE_URL=http://localhost:11434/v1
DASHBOARD_AI_MODEL=…
DASHBOARD_AI_TOOLS=core

Ollama or LM Studio (http://localhost:1234/v1): nothing leaves the machine.

It investigates with read-only tools over what the dashboard already redacted (SQL fingerprints, route patterns, names and types, allowlisted source files), shows every step, and never changes anything. You see the first request before anything is sent. The key is never shown, logged or stored. Budgets: DASHBOARD_AI_DAILY_TOKENS, or a dollar cap with DASHBOARD_AI_DAILY_USD.
