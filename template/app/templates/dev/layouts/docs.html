Docs layout

layouts/docs.html: the top nav, a table of contents beside the text (above it on a phone), and the text at a readable width. Headings with ids are the anchors the contents link to.

Overview

Each page extends layouts/docs.html, fills toc with .toc-link anchors and writes its article in content. Markdown rendered with helpers::markdown_trusted gets heading ids for free.

Install

Nothing to install: the layout is a template in the app. Copy this page to start one of your own.

Requirements

The app layout's head: the CSS, htmx, app.js and components.js, loaded once for every page.

Usage

Long code lines scroll inside their block, never the page: cargo offrails prove fails a page that scrolls sideways at 390 pixels.

Questions

Why a separate layout? Docs need a measure of about 70 characters and a contents list that stays in view; an app page needs neither.
